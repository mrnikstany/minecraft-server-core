# Серверное ядро для Minecraft

Коммерческий проект: серверная часть с HUD, экономикой, магазином, скорбордом и защитой. Плюс клиентская часть, которая рисует интерфейсы в стиле сервера.

> Репозиторий-витрина. Исходный код не публикуется и не передаётся: здесь только описание возможностей и скриншоты. Демонстрация работы по запросу.

## Возможности

- **HUD**: панели обновляются по событиям, а не каждый тик. Страницы переключаются без лагов.
- **Таб и скорборд**: ранги, расы, валюта, статистика, переключение между таблицами.
- **Экономика**: балансы, магазин, донат-привилегии, кейсы, батлпасс.
- **Мобы и спавнеры**: кастомные мобы на дисплеях, настройка спавна без рестарта.
- **Косметика**: шляпы, крылья, эффекты на своих моделях.
- **Защита**: проверки движения, экономики и спавна предметов, лог действий.
- **Клиентская часть**: агент подгружает ресурспак на лету и рисует HUD в стиле сервера.

## Стек

- Java 25, Paper API
- PostgreSQL
- ProtocolLib, PacketEvents
- Maven, ресурспаки на custom_model_data

## Что показываю

- Скриншоты и видео интерфейсов из игры.
- Разбор задач без раскрытия кода: как устроено, что было сложным, как ставится.
- По запросу: короткая демонстрация на тестовом сервере.

## Требования к серверу

- Paper 1.21+
- PostgreSQL 14+
- ОЗУ от 2 ГБ на серверную часть
